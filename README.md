# Student Performance Analytics & Report Management System

A Python-based desktop application developed to manage student academic records and analyse academic performance.

## Overview

This project provides a graphical interface for managing student information, subjects, examination details and marks. It also supports academic performance analysis and report-card generation.

## Technologies Used

- Python
- Tkinter
- MySQL
- Matplotlib
- NumPy

## Key Features

- Student record management
- Subject and examination management
- Marks management
- Academic performance analysis
- Student ranking
- Report-card generation
- Data visualization

## Installation and Setup

1. Clone this repository.
2. Install the required Python dependencies using `pip install -r requirements.txt`.
3. Configure your local MySQL database.
4. Execute the database schema provided in `schema.sql`.
5. Configure your database connection using local environment variables.
6. Run the application's main Python file.
